# Band Song Vote

모바일 우선 공연곡 선정 웹앱.

## 투표 방식

1. 10곡을 무작위로 섞어 5개의 1:1 매치를 만든다.
2. 각 매치 승자 5곡은 생존한다.
3. 탈락한 5곡 중 한 곡을 패자부활시킨다.
4. 생존 5곡 + 부활 1곡 = 6곡 중 한 곡을 최종 탈락시킨다.
5. 최종 공연곡 5곡을 확정한다.

## 실행

정적 웹사이트라 `index.html`을 열면 실행된다. GitHub Pages를 사용할 경우 저장소 Settings → Pages에서 `main` 브랜치의 root를 배포 소스로 지정하면 된다.
